# SuiMint SUIRC-20 index snapshots

Generated by `scripts/suirc20-index.mjs` from on-chain `Operation::{deploy,mint,transfer}` JSON witness transactions (`p=suirc-20`).

- Case-sensitive ticks; first deploy wins
- Mint over `lim` or remaining `max` ignored (no partial fill)
- Transfer requires balance + valid `to`
- Balances are indexer-derived and may differ from the original SuiMint site
